Anime Marker 使用帮助

本地动漫媒体库管理工具 · 本页随程序发布，对应你当前使用的版本

环境要求

项说明
系统Windows 10 / 11
PotPlayer播放功能需要
Lossless Scaling （可选） 播放前自动开插帧
qBittorrent （可选） RSS 下载需要，且要开启 Web UI
Bangumi Token （可选） 收藏同步 / 动态页 / 自动上传需要

除 PotPlayer 外的几项都不是必需的：没配 Token 时程序照常 工作，只是不跟 Bangumi 同步。

首次配置

打开「设置」页，按下面的顺序填一遍即可。

1. Bangumi Token

  • 到 next.bgm.tv/demo/access-token 申请一个，记得勾选「读取收藏」权限（不勾的话收藏同步会失败）。
  • 填写后会校验一次；通过后收藏列表、动态页才会开始工作。

2. 媒体库根目录

  • 填动漫所在的那个目录（例如 F:\动漫）。
  • 多个目录用英文分号 ; 分隔。
  • 扫描按「目录 = 一部动漫」来切分，所以每部番最好各自一个目录。

3. PotPlayer 路径

  • 指向 PotPlayerMini64.exe，播放按钮要用。

不需要任何 PotPlayer 设置 —— 程序通过 PotPlayer 的原生接口 （WM_USER 消息）直接读播放位置，毫秒级精确。
唯一还需要动 PotPlayer 设置的是用插帧的时候：视频渲染器要选 D3D11 那一类（F5 → 视频 → 视频渲染器），否则小黄鸭起来了也不补帧。 那是小黄鸭的要求，跟本程序读进度无关。

4. qBittorrent （用 RSS 下载才需要）

  • 填 Web UI 的地址、端口、用户名、密码。
  • 可以另外填 qBittorrent 的程序路径：它连不上时程序会按需帮你 把它拉起来（qBittorrent 的托盘「退出」会连 Web UI 一起关掉）。

5. 代理 （可选）

  • 国内网络访问 api.bgm.tv 不稳定时可以填。

界面与字体

「设置 → 界面」里可以调整外观和界面字体。

  • 外观模式（亮色 / 暗色）与主题色：选完立即生效，不用点保存。
  • 字体与海报宽度：改完点「保存」生效，海报墙会按新宽度重排。

字体从哪来

类型说明
系统默认跟随 Windows 的界面字体
内置字体「霞鹜文楷 GB 轻便版」，随程序分发，不需要另外安装
用户上传你自己添加的字体，存放在用户数据目录，升级 / 重装不会丢

添加自己的字体

  1. 「设置 → 界面 → 字体」右侧点 上传，选择字体文件。
  2. 支持 .ttf / .otf / .ttc。 默认显示名取字体内部的族名，可以在弹出的窗口里改成任意名字。
  3. 添加成功后立刻出现在下拉菜单里；选中并点「保存」后界面立即切换，不需要重启。
  4. 改显示名或删除：展开字体下拉，在对应条目上点「设置」/「删除」。

也可以直接把字体文件放进字体目录，重新打开软件后会出现在下拉菜单里：
%APPDATA%\AnimeMarker\fonts（安装版）。
同目录下的 fonts.json 只记录显示名，删掉字体文件不会自动清掉里面的条目。

删除了正在使用的字体后，配置里记录的族名会失效，程序会回退到系统默认字体， 不会因此起不来。想换字体时建议先在下拉里切回「系统默认」，再删除旧文件。

看完自动标记

播放到一定进度就自动把那一集标成看过，并同步到 Bangumi。

  • 判定阈值默认为 90%（「触发阈值」）—— 看到九成就算看完。 片尾曲比较长的番可以调小一点。
  • 顺序是「先本地、后远端」：本地观看记录先落袋，再在后台 POST 到 Bangumi。同步失败只提示，不会把本地记录也丢掉 —— 事后可以用「动态」页的「上传」补传。
  • 「看完立即同步」关掉后只写本地，什么时候上传由你自己决定。
  • 「自动完结」：一部动漫的每一集都看完后，自动把它整条标成 「看过」。

没填 Token 时这些开关一样有效 —— 本地记录照写， 只是不往 Bangumi 传。之后补上 Token，可以在「动态 → 上传」里一次补齐。

RSS 订阅怎么用

  1. 在 qBittorrent 里开启 Web UI（设置 → Web UI）， 并在本程序「设置」页填好地址与账号。
  2. 到「订阅」页新增一条订阅源：填 RSS 链接、选择保存路径。
  3. 规则选 「仅新条目」：只推送订阅之后新出现的条目， 不会把历史剧集一次性全下一遍。
  4. qBittorrent 里下载完成后，程序会自动扫描该条目并把新集入库， 所以在看页的进度会自己跟上。

轮询

  • 「自动轮询」开着（默认）：启动时检查一次，之后每 30 分钟一次。
  • 关掉后不再自动请求，只在点「立即检查」时抓一次 —— 不想让它自己下东西就用这个。

数据、备份与迁移

所有用户数据都放在一个目录里，位置取决于运行方式：

运行方式用户数据目录
安装版 / 打包版%APPDATA%\AnimeMarker\
源码运行项目根目录下的 data\（配置文件在项目根的 config.ini）

目录里是什么

文件 / 目录内容
config.ini设置、Bangumi Token、路径、快捷键
anime.db媒体库、观看进度、订阅规则
covers\Bangumi 封面缓存
thumbs\缩略图缓存
fonts\你上传的字体
logs\运行日志（单文件 2 MB 滚动，最多保留 3 份）
config_backups\配置结构升级前的自动备份，最多保留 3 份

备份、迁移与重置

  • 备份：先关闭程序，把整个用户数据目录复制到别处即可。
  • 迁移到新电脑：装好程序后，把备份目录放回同一位置。
  • 彻底重置：关闭程序后删除整个用户数据目录 —— 媒体库、观看进度、Token 都会丢失，请先备份。
  • 升级或重装程序本身不会动这个目录，数据会保留。

config.ini 里的 Token 使用 Windows DPAPI 加密保存， 密钥由 Windows 按当前登录用户托管，程序本身不保存密钥。
代价是它绑定当前 Windows 用户：换电脑、换 Windows 账户或重装系统后解不开， 需要在设置里重新填写 Token。

快捷键

「设置 → 启动器与监控」里有两个可录制的快捷键：

  • 全屏快捷键：程序把播放器切到全屏时使用。
  • 小黄鸭快捷键：播放前自动开插帧时使用。

设置方式：点一下输入框，然后直接按组合键。程序会提示该组合是否已被其他软件占用， 被占用时可能收不到按键，建议换一个。

看完自动标记不需要快捷键，程序按播放进度自动判断，详见 「看完自动标记」一节。

更新与隐私

检查更新

  • 自动：每天第一次启动时静默检查一次。有新版本时只在「更多」菜单里点亮一个小红点， 不弹窗、不打断使用。
  • 手动：「更多 → 检查更新」。有新版会直接打开发布页；已是最新会在状态栏给一句提示。
  • 当前版本号在「更多 → 关于」里；本帮助页也随程序版本一起发布。

联网范围

  • api.bgm.tv：搜索条目、同步收藏与进度、下载封面。
  • 你自己添加的 RSS 源。
  • 你填写的 qBittorrent Web UI 地址。
  • GitHub：检查更新、打开反馈页。

程序不收集使用统计，也不会上传你的媒体库内容。记录只写在本机的 anime.db； 离开本机的只有你主动同步到 Bangumi 的收藏与进度，以及上面这些请求本身。

常见问题

扫描后匹配到了错误的条目

  • 扫描按「一个目录 = 一部动漫」切分，尽量让每部番各占一个目录。
  • 匹配错的条目进详情页点「重新匹配」，或在「待确认」里手动指定。

海报墙是灰底加一条横线

这是没有封面时的占位样式，不是故障。封面在匹配成功后才下载； 网络不通或 Bangumi 上没有封面时会一直保持占位。

播放了但进度没记录

  • 确认「设置 → 路径」里的 PotPlayer 指向 PotPlayerMini64.exe。
  • 进度通过 PotPlayer 的原生接口读取，用其他播放器打开不会记录。
  • 没到「触发阈值」（默认 90%）也不会记录；片尾长的番可以调低。
  • 仍然不行就打开日志，里面会写明读取失败的原因。

连不上 Bangumi

  • 确认 Token 申请时勾选了「读取收藏」权限。
  • 国内网络不稳定时，在「设置 → Bangumi」里填代理。
  • 程序的错误提示会区分服务端故障与本地网络 / 代理问题。

qBittorrent 连不上

  • 先在 qBittorrent 里开启 Web UI，并核对地址、端口、账号、密码。
  • qBittorrent 从托盘「退出」会连 Web UI 一起关掉；填了它的程序路径时， 本程序会尝试帮你拉起来。

换了字体但界面没变

确认选完字体后点了「保存」。字体文件损坏或格式不支持时不会出现在下拉里； 删除了正在使用的字体会回退系统默认，重新选一个即可。详见「界面与字体」。

遇到问题

  • 先看日志：状态栏最右侧「更多」→ 打开日志目录， 里面是运行记录，多数问题都能看出原因。
  • 要反馈的话：「更多」→ 反馈问题， 会自动带上版本号与系统信息，你只要写清楚现象和复现步骤。
  • 检查更新：同一个菜单里，有新版本时那一行右边会点一个小红点。
