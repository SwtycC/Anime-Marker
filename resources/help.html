Anime Marker 使用帮助

本地动漫媒体库管理工具 · 本页随程序发布，对应你当前使用的版本

环境要求

项说明
系统Windows 10 / 11
PotPlayer播放功能需要
Lossless Scaling （可选） 播放前自动开插帧
qBittorrent （可选） RSS 下载需要，且要开启 Web UI
Bangumi Token （可选） 收藏同步 / 动态页 / 自动上传需要

除 PotPlayer 外的几项都不是必需的：没配 Token 时程序照常 工作，只是不跟 Bangumi 同步。

首次配置

打开「设置」页，按下面的顺序填一遍即可。

1. Bangumi Token

  • 到 next.bgm.tv/demo/access-token 申请一个，记得勾选「读取收藏」权限（不勾的话收藏同步会失败）。
  • 填写后会校验一次；通过后收藏列表、动态页才会开始工作。

2. 媒体库根目录

  • 填动漫所在的那个目录（例如 F:\动漫）。
  • 多个目录用英文分号 ; 分隔。
  • 扫描按「目录 = 一部动漫」来切分，所以每部番最好各自一个目录。

3. PotPlayer 路径

  • 指向 PotPlayerMini64.exe，播放按钮要用。

不需要任何 PotPlayer 设置 —— 程序通过 PotPlayer 的原生接口 （WM_USER 消息）直接读播放位置，毫秒级精确。 老教程里那条「F5 → 基本 → 消息 → 在屏幕上显示播放信息」不用开： 它只控制画面上的 OSD，跟播放位置无关。
唯一还需要动 PotPlayer 设置的是用插帧的时候：视频渲染器要选 D3D11 那一类（F5 → 视频 → 视频渲染器），否则小黄鸭起来了也不补帧。 那是小黄鸭的要求，跟本程序读进度无关。

4. qBittorrent （用 RSS 下载才需要）

  • 填 Web UI 的地址、端口、用户名、密码。
  • 可以另外填 qBittorrent 的程序路径：它连不上时程序会按需帮你 把它拉起来（qBittorrent 的托盘「退出」会连 Web UI 一起关掉）。

5. 代理 （可选）

  • 国内网络访问 api.bgm.tv 不稳定时可以填， 格式形如 http://127.0.0.1:7890。

看完自动标记

播放到一定进度就自动把那一集标成看过，并同步到 Bangumi。

  • 判定阈值默认为 90%（「触发阈值」）—— 看到九成就算看完。 片尾曲比较长的番可以调小一点。
  • 顺序是「先本地、后远端」：本地观看记录先落袋，再在后台 POST 到 Bangumi。同步失败只提示，不会把本地记录也丢掉 —— 事后可以用「动态」页的「上传」补传。
  • 「看完立即同步」关掉后只写本地，什么时候上传由你自己决定。
  • 「自动完结」：一部动漫的每一集都看完后，自动把它整条标成 「看过」。注意判定用的是「看过的集数 ≥ 官方集数」，所以跨季连续 编号的番（比如从第 73 集开始编号的第四季）也会按本季集数算。

没填 Token 时这些开关一样有效 —— 本地记录照写， 只是不往 Bangumi 传。之后补上 Token，可以在「动态 → 上传」里一次补齐。

RSS 订阅怎么用

  1. 在 qBittorrent 里开启 Web UI（设置 → Web UI）， 并在本程序「设置」页填好地址与账号。
  2. 到「订阅」页新增一条订阅源：填 RSS 链接、选择保存路径。
  3. 规则选 「仅新条目」：只推送订阅之后新出现的条目， 不会把历史剧集一次性全下一遍。
  4. qBittorrent 里下载完成后，程序会自动扫描该条目并把新集入库， 所以在看页的进度会自己跟上。

轮询

  • 「自动轮询」开着（默认）：启动时检查一次，之后每 30 分钟一次。
  • 关掉后不再自动请求，只在点「立即检查」时抓一次 —— 不想让它自己下东西就用这个。

遇到问题

  • 先看日志：状态栏最右侧「更多」→ 打开日志目录， 里面是运行记录，多数问题都能看出原因。
  • 要反馈的话：「更多」→ 反馈问题， 会自动带上版本号与系统信息，你只要写清楚现象和复现步骤。
  • 检查更新：同一个菜单里，有新版本时那一行右边会点一个小红点。
